    GUIDE

    도움말

    처음 사용하기
    1. 회원가입 후 내 학교 포털 계정을 연결합니다. 로그인 확인에 성공한 정보만 저장합니다.
    2. 작성할 월을 고르고, 배정 조회·선택에서 장학 유형과 근무지를 선택합니다.
    3. 일정을 만들고 일정 저장으로 보관합니다.
    4. 기록만 조회로 기존 일지를 확인한 뒤 자동 입력 시작에서 실제 등록할 내용을 확인합니다.
    일정 추가·복사·삭제
    • 날짜를 누르고 출퇴근 시간을 적용하면 수동 예정 일정이 생깁니다. 구간 추가로 점심시간 전후처럼 하루 1~8개 구간을 나눌 수 있습니다. 구간 사이의 시간은 합계에서 제외합니다.
    • 시간칸을 누르면 기존 값이 선택됩니다. 9 → 09:00, 930 → 09:30처럼 짧게 입력할 수 있으며, 퇴근은 24:00까지 가능합니다.
    • 수동 예정 일정을 같은 월의 빈 날짜로 드래그하면 바로 시간을 복사합니다. 원본은 유지합니다.
    • 모바일·키보드에서는 날짜 상세창의 복사할 날짜와 일정 복사를 사용하세요.
    • 공휴일·추가 지정 휴일이거나 기존 예정 일정·포털 기록이 있는 날짜에만 확인 모달을 표시합니다. 같은 시간의 예정 일정이 이미 있으면 아무것도 바꾸지 않습니다. 근무내용과 배정은 현재 월의 공통 설정을 사용합니다.
    • 예정 일정만 삭제는 수동 일정과 반복 일정이 함께 있으면 수동 일정만 지우고 반복 일정으로 돌아갑니다. 수동 일정만 있으면 빈 날짜가 되고, 반복 일정만 있으면 그날만 제외합니다. 다른 날짜와 포털 기록은 유지합니다.
    • 변경 후 일정 저장을 눌러 보관하세요. 예정 일정 편집·복사만으로 포털에 등록되지는 않습니다.
    요일 반복·공휴일
    • 요일 반복은 설정한 월부터 직접 바꾸기 전까지 계속 이어집니다. 나중 월에서 바꾸면 그 월부터 새 규칙을 사용하며, 이전 월과 다른 사용자의 일정은 유지합니다. 이미 따로 설정한 미래 월의 반복 규칙도 유지합니다.
    • 날짜별 수동 일정·제외일·근무내용·배정은 월별 설정입니다. 월을 이동할 때 편집 중인 일정은 앱에 자동 저장하며, 포털에는 등록하지 않습니다. 근무내용은 비워두어도 됩니다.
    • 반복 설정도 요일마다 여러 근무 구간을 추가할 수 있습니다. 날짜별 수동 설정은 그날의 반복 구간 전체를 대신하고, 근무 제외는 그날의 모든 구간을 제외합니다.
    • 공휴일은 빨갛게 표시하고 기본적으로 제외합니다. 실제로 일했다면 날짜 상세창에서 공휴일 근무를 선택하세요.
    • 공휴일 근무 예외를 선택해도 학교 포털의 입력 제한을 해제하는 것은 아닙니다. 공휴일 조회 오류는 달력에 별도로 표시합니다.
    포털 기록 조회·수정·삭제
    • 포털 연결 후 첫 접속과 월 변경 시 승인된 근무지 배정·일지를 자동 조회합니다. DB의 이전 조회 기록을 먼저 보여주고 완료 후 갱신합니다. 1분 이내 조회 결과는 재사용하며, 기록만 조회로 즉시 갱신할 수 있습니다.
    • 자동 조회는 포털에 일지를 등록하지 않습니다. 국가·일반근로를 구분하며 예정 일정의 시수와 별도로 집계합니다. 조회 실패 시 이전 기록과 조회 시간을 유지합니다.
    • 달력의 포털 기록은 마지막 조회 시각 기준입니다. 학교에서 바뀐 내용은 다시 조회해야 반영됩니다.
    • 날짜를 눌러 포털 일지의 시간·내용을 수정하거나 삭제할 수 있습니다. 실제 변경 동의 후 원본을 다시 확인하고 처리 결과를 재조회합니다.
    • 확인 완료 일지는 수정·삭제할 수 없습니다. 학교 담당자에게 문의하세요. 날짜·배정 자체를 바꾸는 직접 수정도 지원하지 않습니다.
    • 포털 일지를 삭제해도 예정 일정은 남습니다. 재등록하지 않으려면 날짜 상세창에서 이 날짜를 근무에서 제외를 선택하고 적용한 뒤 일정을 저장하세요.
    매월 자동 실행
    • 포털 자동화 → 매월 자동 실행에서 날짜, 한국 시간, 실행하는 달 또는 지난달, 기본 배정을 선택하고 예약을 켭니다. 실제 학교 포털 등록 동의를 확인한 뒤 저장합니다. 기본값은 꺼짐입니다.
    • 대상 월에 저장된 일정·배정이 우선입니다. 별도 월 일정이 없으면 계속되는 반복 규칙과 예약의 기본 배정으로 만들며 근무내용은 비워둡니다. 편집 후 저장하지 않은 내용은 실행에 반영되지 않습니다.
    • 브라우저나 사용자 PC를 꺼도 서버가 실행 중이면 예약이 동작합니다. 29~31일이 없는 달에는 말일에 실행하며, 실행 시각은 한국 시간입니다. 저장할 때 이미 지난 시각은 다음 달부터 적용합니다.
    • 기록이 있는 날짜는 장학 유형·근무지와 관계없이 전체를 건너뜁니다. 비어 있던 날의 여러 구간은 모두 등록합니다. 배정·승인 기간·공휴일·근로시간 한도를 다시 확인합니다.
    • 배정 승인이 아직 확인되지 않았고 저장 요청이 없었던 경우만 다음 날 다시 확인합니다. 다음 정기 예약 전까지 하루 한 번 확인하며, 예약 설정 변경·해제로 대기를 취소할 수 있습니다. 로그인·통신·저장 오류는 재시도하지 않습니다.
    • 서버 중단이나 다른 작업으로 지연되면 예약 시각 24시간 이내에 실행합니다. 그 이후는 건너뜁니다. 최근 작업과 예약창에서 다음 확인 시각을 볼 수 있습니다.
    • 포털 계정을 변경·삭제하거나 앱 계정이 비활성화되면 예약은 꺼집니다. 예약을 끄면 이후 실행은 멈추지만 이미 전송 중인 작업을 되돌리지는 않습니다. 배포 중에는 새 예약 작업을 시작하지 않습니다.
    자동입력과 지원 범위
    • 자동입력은 현재 월에 선택한 장학 유형·근무지로 진행합니다. 날짜별로 서로 다른 배정을 자동 분리하는 기능은 아직 지원하지 않습니다.
    • 예정된 근무도 미리 등록할 수 있습니다. 승인기간, 공휴일, 근로시간 한도를 검사하고 저장 결과를 다시 확인합니다.
    • 어느 배정이든 해당 날짜에 일지가 있으면 그날은 전체를 건너뜁니다. 빈 날짜의 여러 근무 구간은 모두 입력합니다. 기존 일지를 고칠 때는 날짜 상세의 수정 기능을 사용하세요.
    • 이전 달 가져오기는 이전 달 예정 일정을 같은 일자로 복사해 현재 월의 입력 대기로 저장합니다. 현재 월 예정 일정은 교체하지만 요일 반복 규칙·배정·내용은 유지합니다. 없는 날짜는 제외하고 공휴일은 현재 월 기준이며, 이 버튼 자체는 포털에 전송하지 않습니다.
    • 학교 응답이 불확실하면 무작정 다시 저장하지 않습니다. 기록을 조회해 결과부터 확인하세요.
    • 학생 본인에게 허용된 조회·등록·수정·삭제를 지원합니다. 직원용 승인 처리나 다른 학생의 일지 관리는 지원하지 않습니다.
    계정과 개인정보
    • 앱 로그인과 학교 포털 로그인은 별도입니다. 계정마다 일정·조회 기록·포털 정보가 분리됩니다.
    • 학교 포털 아이디와 비밀번호는 로그인 확인 후 서버에 AES-256-GCM으로 암호화해 보관합니다. 앱 비밀번호는 복호화할 수 없는 해시로 저장합니다.
    • 포털 계정 설정에서 연결 정보를 변경하거나 삭제할 수 있습니다. 연결 정보를 삭제해도 학교 포털의 일지는 삭제되지 않습니다.
